🌐 1. การตั้งค่า PXE Server & บริการ DHCP

กำหนด IP ของเครื่องโฮสต์ที่รัน PXE Server และช่วงการแจก IP ให้เครื่องลูก

💡 ProxyDHCP Mode: Dnsmasq จะไม่แย่งแจก IP แต่จะดักฟัง DHCP Request ของเครื่องลูกและส่งเฉพาะไฟล์ PXE Boot (Next-Server / Bootfile) เหมาะสำหรับเครือข่ายออฟฟิศหรือบ้านที่มี Router หลักอยู่แล้ว

👤 2. บัญชีผู้ใช้ & ความปลอดภัย (Target System Credentials)

ระบบจะนำข้อมูลนี้ไปสร้างผู้ใช้ Administrator และเข้ารหัสผ่านเป็น SHA-512 ($6$) สำหรับ /etc/shadow อัตโนมัติ

🔌 3. การตั้งค่า Network เครื่องลูก (Installed OS Network)

กำหนดว่าเมื่อเครื่องลูกติดตั้งเสร็จแล้ว ให้รับ IP แบบใด

📦 4. แพ็กเกจเพิ่มเติม (Pre-installed Packages)

แพ็กเกจ APT ที่จะติดตั้งเพิ่มเติมให้อัตโนมัติ (คั่นด้วยเครื่องหมายจุลภาค)
